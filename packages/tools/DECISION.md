
## 2026-09-02 — Phase 5: sandbox, browser, meetings, constitution enforcement
- Sandbox image `cubicle-sandbox` (config/sandbox/Dockerfile, from `node:26-bookworm` with pnpm, astro, create-astro preinstalled). Default `--network none`; `network: allowlist` runs on the bridge with `HTTP(S)_PROXY` pointed at a daemon-side allow-list proxy bound to the Docker gateway (advisory: a process may ignore proxy vars; kernel-level egress filtering is parked). Containers run as the host uid/gid so `Site/` stays owner-editable; `--memory 2g --cpus 2 --pids-limit 512`, 5-minute cap.
- No Docker → restricted local shell in the job's scratch workspace with a minimal environment, announced by `daemon.warning`.
- After every `shell.run` the daemon rescans `Site/` (excluding `dist/` and `node_modules/`) into `written_sha` as `<role>/shell`, so owner-edit detection stays exact.
- Browser: Playwright persistent profile in `.cubicle/browser`; CDP `Page.startScreencast` (jpeg, 640×440, q45) throttled to ≤ 5 fps at the daemon; frames saved as `.cubicle/screens/<session>/<seq>.jpg`, indexed in the `screens` table, announced by `browser.frame {session, seq, path}` (no bytes in the event log) and pushed to the viewer through the WS `frame` op. Two concurrent sessions max; idle sessions close after 10 min. `browser.submit` is the outbound (ask-mode) form action; `browser.type` never submits.
- `Site/` owner-edit safety (R34): an existing `Site/` file whose sha differs from `written_sha` is read-only for agents; the tool tells the agent to ask the owner via a `message` proposal.
- Meetings: `meeting.open` runs round-robin turns through the router (≤ 3 rounds, 300 output tokens each), writes `Meetings/<ts>-<room>-<id>.md` and a `Decisions/` note with the spec's sections; the CEO heartbeat calls it when ≥ 2 jobs failed since the last heartbeat.
- Constitution enforcement lives in `packages/tools/src/guardrails.ts` and runs inside the harness before any tool call: `max_emails_per_day` (counts `email.sent` since UTC midnight), `banned_channels` (social.post), `max_roles` (hire proposals), `banned_tactics` (substring match, then the local model as a yes/no classifier; fails open when no local model answers), `never_modify` (vault guard), `pii_local_only` (harness routing).
